The font in this folder (DejaVuSerif-Bold.ttf) is bundled so certificate text
renders correctly regardless of what fonts are installed on the host server.

DejaVu fonts are based on the Bitstream Vera fonts and are released under a
permissive, freely redistributable license — see DEJAVU_LICENSE.txt in this
folder for the full text. No attribution is required in generated
certificates, but the license file is kept here for compliance.
